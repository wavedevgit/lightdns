# LightDNS Dashboard Design

The dashboard is a dense dark infrastructure console. Pico CSS owns standard controls, forms, tables, switches, buttons, dialogs, and focus behavior; project CSS supplies the shell, responsive navigation, compact data treatment, and tokens.

## Tokens

- Ink: `#f1f3f4`
- Muted ink: `#9ca2a8`
- Canvas: `#0a0b0c`
- Surface: `#101112`
- Active surface: `#272829`
- Line: `#303234`
- Action blue: `#2f7df4`
- Brand orange: `#d86d1c`

Use the system sans stack and fixed type sizes. Keep controls familiar, corners restrained, state color purposeful, and data dense. Desktop uses a near-black masthead, full-height rail, compact toolbars, and bordered data tables; mobile turns the rail into horizontal navigation and records into editable rows. Avoid decorative diagrams, metric-card grids, gradients, glass, invented controls, and explanatory filler.
